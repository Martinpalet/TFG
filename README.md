# TFG
Trabajo TFG pagina web dedicada a un Laboratorio dental con enseñanzas bucodentales 
Exposición del Trabajo de Fin de Grado: Desarrollo de una Página Web para un Laboratorio Dental

Para mi Trabajo de Fin de Grado del ciclo formativo de Desarrollo de Aplicaciones Web, he elegido desarrollar una página web informativa para un laboratorio dental. Este proyecto tiene como objetivo principal mejorar la presencia online del laboratorio, facilitando el acceso a información relevante para sus clientes y colaboradores.

La estructura de la página web estará diseñada para ser clara, accesible y responsive, es decir, adaptable a distintos dispositivos como ordenadores, tabletas y móviles. La web contará con una página de inicio desde la cual se podrá acceder a las distintas secciones mediante botones de navegación intuitivos. Las secciones principales serán las siguientes:

1. Salud Bucodental: Una página dedicada a la educación del usuario sobre la importancia del cuidado bucodental, con consejos, recomendaciones y artículos informativos.

2. Tratamientos: Sección donde se detallarán los tratamientos que ofrece el laboratorio, explicando en qué consisten, su finalidad y posibles beneficios.

3. Materiales: Página destinada a informar sobre los materiales utilizados en los diferentes procedimientos, destacando sus características, calidad y ventajas.

4. Contacto: Formulario de contacto y datos del laboratorio (dirección, teléfono, correo electrónico, etc.), que permitirá a los usuarios comunicarse de forma directa para resolver dudas o solicitar servicios.
